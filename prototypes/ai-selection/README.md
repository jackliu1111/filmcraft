# FilmCraft AI 选片 · 可丢弃交互原型

2026-10-13。本轮原型回答：**把枪声／人声识别子行放进原片音频轨下，再把选片作为声画关联单元放到同一条剪辑轨并自动拼接，是否更顺手？** 用户已选 A 双行方向，并进一步要求创建的画面和关联声音处于同一轨道、自动拼接。此前逐次新增 V2/A2、V3/A3 的多轨方案已被取代；各轮实际检查范围见 [CAPTURE.md](CAPTURE.md)，旧多轨证据不代表本轮修订已通过验证。

这是浏览器交互演示，不是 FilmCraft 原生实现。声音事件、分数、波形和分析进度均为演示数据；画面来自本机录像的 0–120 秒静音低清代理。无模型调用、上传、真实导出、磁盘工程写入或浏览器持久化。刷新页面会清空状态，“保存快照／模拟重开”只使用本页内存。

## 启动

在仓库根目录执行：

```sh
python3 prototypes/ai-selection/serve.py
```

打开 [本地原型](http://127.0.0.1:8791/?variant=A)。也可直接打开本目录 `index.html`；视频预览推荐用上述本地服务，并使用完整桌面浏览器窗口。

服务仅绑定本机，根目录固定在此原型目录；没有接口读取任意本地路径。

## 本轮操作路径与未覆盖边界

以下列出当前操作路径和验证目标，不表示每项均已在本轮复测；执行结果和未覆盖行为以捕获记录中的对应轮次为准。此前轨道对创建与目标轨道内插入的检查是历史记录，不证明当前单轨拼接行为。

1. 展开 A1 下的枪声、人声子行，点击高亮定位预览；缩放和移动播放头时，原片 V1/A1 与分类高亮一起对齐。拖左右手柄或输入起止秒数，只改变待剪范围。
2. 拖高亮主体到剪辑轨空白处，预览落点并追加末尾；或用 Shift+Enter 追加选中的待剪范围。拖到已有片段附近时吸附片段边界插入，后续整体顺延，不覆盖已有片段。所有片段在同一行连续排列，不改变原片参照或分类行。Esc／无效落点取消。
3. 调整已复制片段的原片起止，或删除其关联声画；缩短、删除后后续片段自动合拢，延长后顺延。确认原片待剪范围与时间线片段双向独立，一次撤销包含本次片段内容及位置变化。
4. 空白识别区可划选手动补片。重复使用只提示未使用、部分重叠或已使用，不自动删减；提示随当前时间线更新。
5. “按当前范围生成草稿”使用已调整范围；未调整项用默认范围。可包含人声，合并重叠；产生只读原稿与独立副本，原手动序列保留。
6. 用序列下拉框切换手动选片、组稿原稿、编辑副本；每个当前序列以同一条剪辑轨展示连续片段，节目预览按片段顺序播放。片段之间自动衔接，序列范围外显示黑场。
7. 演示导入可体验单音轨自动分析、多音轨选择、排队及取消。本地视频选取只替换预览并重新按长度映射演示标记，不代表识别了该视频；静音代理不提供真实音轨试听。
8. 保存快照、修改、模拟重开，检查状态恢复。刷新页面丢失所有快照；这不是持久化验收。

保留键盘替代操作。`Shift+Enter` 将当前待剪范围追加到剪辑轨末尾；`Ctrl/Cmd+Z` 撤销时间线操作，`Delete/Backspace` 删除选中编辑片段；边界手柄用左右方向键调整 0.1 秒，按住 Shift 为 1 秒。各按键路径是否复测见本轮捕获记录。

旧版“操作导览”的范围独立、手动重叠与组稿合并、内存快照恢复场景仍可作为回归依据；本轮以声画同一单元、末尾追加、边界插入、删改自动合拢及对应撤销为验证重点。

## 边界与结论

- 已确定的产品决策来自 `docs/ai-selection/design/recognition-workspace.md`；原型只用于体验它们，不反向宣称模型效果、原生性能或正式迁移已通过。
- 两分钟代理为 640×360、12 fps、静音；时间标签是交互状态，不代表逐帧剪辑或声画同步验收。
- 项目分栏、音轨混音、特效、任意原生工程载入和实际导出没有在此演示中实现。
- 无生产构建入口；所有文件明确位于 `.prototype` 目录，本轮不会接入正式应用。
- **用户已选择 A 的双行呈现，并修订为同一剪辑轨中的声画关联单元自动拼接。** 当前验证应独立记录，用户体验结论仍待试用；旧版 A/B/C 和多轨方案的检查不能替代本轮验证。

实际拖拽、点击、键盘及布局检查的有界证据按轮次记录于 [CAPTURE.md](CAPTURE.md)，截图仅代表其对应记录中的版本；最新[单轨原型截图](evidence/prototype-single-track.jpg)随本次同步保留。当前网页原型与 grill 文档位于 `codex/grill-ai-selection-decisions` 分支，本地临时分支不作为使用前提。产品约定统一维护在[AI 识别与选片方案](../../docs/ai-selection/design/recognition-workspace.md)，不再在原型目录重复保存设计正文。
