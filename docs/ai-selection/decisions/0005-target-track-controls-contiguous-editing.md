# 连续拼接由目标剪辑轨决定

用户在 Q16 选择：AI 选片与普通素材进入同一剪辑轨时都使用追加、插入顺延及删改合拢，其他原生轨道保留原有编辑方式。相比仅对 AI 拖入增加特殊规则，这要求剪辑序列保存明确的编辑语义并使相关声画操作一致，但避免用户在同一轨道因素材来源不同而得到覆盖或拼接两种结果。

这一决定不把完整原片参照加入成片渲染，也不取消视频与多路音频的底层区分。Q18 明确分析音轨选择不决定成片保留音轨；声画单行展示仍默认保留原有声音。已确认的产品边界见[AI 识别与选片方案](../design/recognition-workspace.md#原生改造前收口)。
