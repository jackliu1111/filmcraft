# 首版采用纯音频模型检测，标注与训练延后

用户希望先方便地分析本地 Apex 录屏并导出枪声候选，画面截图与识别会增加处理成本，因此首版确定采用纯音频模型检测，不接入 HUD/OCR 或其他画面检测。服务保留独立的原始预测及时间、类别和模型元数据，候选合并、复核和导出消费预测结果；人工标注与训练预处理放到后续阶段。

这一范围优先验证处理链路和使用便利，接受通用枪声模型暂时无法证明本人开枪、命中或高光语义的限制。后续模型升级应通过适配器统一输出；若目标类别或输入模态改变，仍需调整适配与选片规则并重新评估，而非只替换权重。

服务职责、处理规则和验证边界见 [本地模型服务方案](https://github.com/jackliu1111/apex-fps-mvp/blob/978fed1580fdf85d34e2b5c17f973693c5510693/docs/design/model-service.md)。
