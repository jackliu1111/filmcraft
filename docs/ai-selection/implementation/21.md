# #21：导入后枪声识别与原片子行

2026-10-16。实现分支 `codex/ai-recognition-21`。本记录不替代真实原生验收，不据此关闭工单。

## 实现

- 复用公共媒体导入入口，在成功安装本地声画素材时记录一次分析请求。桌面适配器依次调用已有 `bridge.py probe/analyze`；单音轨自动分析，多音轨显示选择入口，无音轨显示不可分析。
- 复用参考补丁的 NDJSON 进度、取消和子进程清理；分析完成仅通过 `recognition.attach` 保存关联，不创建序列、移动片段或触发组稿。`apexAi.apply` 保留为显式组稿操作，继续使用独立原稿与编辑副本。
- `recognition.begin {item,audioStream}` 返回运行时 `token`；`recognition.attach {token,result}` 统一核对捕获素材、文件大小/修改时间、结果版本、音轨参数、原片时长与事件范围。`recognition.cancel {token}` 使迟到结果失效。
- Session 的识别任务表在新建、打开、恢复、关闭或模板替换工程时更换。普通编辑、保存和历史裁剪不改变任务所属工程；切换源预览只允许结果关联捕获的原素材。
- 完成记录位于 `Project.recognition`（默认空、兼容旧文件），保留完整模型结果与类别字段。原始事件与模型候选范围分别保存。
- 新模块 `source_recognition` 在原生主时间线上方绘制 V1/A1 原片参照与 A1 下的枪声分类子行，使用当前时间线缩放/滚动；原片时长纳入视口导航范围，原片区复用原生滚轮/缩放语义。参照属于显示数据，不是渲染片段。单击事件只定位源预览，悬停只显示提示；保留现有 dock 布局。

## 公共验收入口

控制通道使用现有 `engine.execute` 与 `ui.menu.invoke`：

- 导入：`engine.execute {command:"file.import",params:{paths:[绝对路径]}}`。导入后自动探测和分析。
- 状态：`ui.menu.invoke {command:"apexAi.inspect",params:{}}`；原生任务阶段、进度、消息、来源路径与逐素材状态。
- 结果：`engine.execute {command:"recognition.inspect",params:{item:素材ID}}`。完成记录包含 `status:"completed"`、`audioStream`、`sourcePath`、`result`。
- 取消：`ui.menu.invoke {command:"apexAi.cancel",params:{}}`。
- 显式操作：`apexAi.open {item}` 读取对应已保存记录；`apexAi.probe`、`apexAi.analyze` 可重试；`apexAi.apply` 显式组稿。
- UI 元素：`recognition.open`、`recognition.gunshot.toggle`、`recognition.gunshot.event.N`（N 从 0 开始，只有当前视口内事件可点击）。

无需配置即可从主仓库或标准 Git worktree 定位桥与相邻模型 Python。环境变量 `FILMCRAFT_APEX_PYTHON`、`FILMCRAFT_APEX_BRIDGE`、`APEX_SERVICE_ROOT` 等显式配置优先。

## 验证

- 首切片先得到 `UnknownCommand("recognition.begin")` 的失败，再通过“只关联、不组稿、不改变已有序列”的测试。
- 音轨参数不匹配先得到错误接收的失败，再补齐采样率/声道校验并通过。
- `cargo test -p filmcraft-engine recognition_ --offline --lib`：4 passed，覆盖关联、音轨拒绝、取消/换工程迟到保护、切换源后仍附着原项，以及实际磁盘保存/新会话打开恢复。测试使用明确标为合成的媒体记录与临时文件，不证明真实模型或解码正确。
- `cargo check -p filmcraft-ui-egui --offline`：通过（默认 dev profile，共享的已构建 target）。
- 上游共享引擎真实录像分析由集成负责人另行验证；尚未证明本分支原生自动触发、事件点击、进程重启、显式组稿与实际导出。

## 当前限制

- 本票只接受零视频起点、默认媒体解读、单音轨结果；多音轨选择界面已保留，但结果映射在 #27 完成之前会明确拒绝，不把音轨顺序当作容器索引。
- 工作区识别参照与成片时间线共用缩放/滚动，但原片和成片播放头保持独立；原片时间有明确标识。
- 源参考区依赖时间线面板有足够高度（112 px，折叠 86 px）；小面板暂不自动调整用户布局。
- 未完成任务属于运行时，不随工程恢复或自动重启；已完成关联随工程保存。队列控制与完整恢复行为由后续工单完善。
- 待剪范围编辑、拖拽创建、人声识别与完整组稿版本策略仍按后续工单实现。
