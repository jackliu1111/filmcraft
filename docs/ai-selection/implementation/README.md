# AI 选片实现与验收

2026-10-16。集成分支：`codex/ai-selection-integration`。方案以 [Q1–Q19](../design/recognition-workspace.md) 为准，工单仍在 [Apex #21–#32](../tickets/published.md)。

## 用户已确认的测试接口

1. `Session::execute`：复用 `timeline.place`、`sequence.inspect`、`edit.undo`、`edit.redo` 等公开命令验证连续剪辑、来源范围、关联声画和事务。
2. `integrations/apex-ai/bridge.py probe/analyze`：通过请求与 NDJSON 结果验证路径、音轨、错误及取消协议。
3. 编辑器公开的分析结果接收入口：验证任务、工程实例、素材及分析音轨身份；分析完成只更新识别关联，不自动组稿；取消或切换工程后的迟到结果不能改写当前工程。
4. `file.save` / `file.open`：写入真实临时工程文件，再以新会话打开，验证识别、人工范围、轨道身份、片段和任务恢复；跨工程不复用人工调整。

按 TDD 逐个行为完成失败测试与最小实现。原生指针交互、真实模型效果、应用进程重启和实际媒体导出另外验收，自动测试不代替这些证据。

## 验收素材边界

- 已定位本机真实单音轨录像 `2026-08-09 15-31-44.mkv`：496.65 秒、3840×2160、60 fps、H.264、AAC 双声道。原文件不随源码提交。
- 用户确认当前没有游戏声与麦克风分轨的真实录像。多音轨实现可用本地可控样本验证，但 #27 和 #32 要求的真实分轨声音验收保留为待验证。
- 大型模型、完整预测、录像、原生截图和导出文件放在忽略的 `outputs/` 下。这里只记录版本、复现入口和有界结论。
