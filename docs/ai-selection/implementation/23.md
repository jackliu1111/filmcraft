## 复用和行为

沿用同一个共享模型、完整预测缓存、来源／音轨／模型配置校验及公共 `ModelService.read_scores` 分页接口。FilmCraft 入口等待后端完成并释放服务，再读取已验证的预测；不读取返回载荷提供的任意 `scores_path`，不修改外部后端全局对象，不重复加载模型或推理。

FilmCraft Python 适配层负责明确版本化的 `filmcraft-spoken-voice-v1` 后处理策略；此策略与模型配置版本分开。固定消费十类：`Speech`、`Male speech, man speaking`、`Female speech, woman speaking`、`Child speech, kid speaking`、`Conversation`、`Narration, monologue`、`Whispering`、`Speech synthesizer`、`Shout`、`Children shouting`。按每份分数的类别名称查找列，不依赖类别顺序。每列做三帧对称边界中值滤波，严格 `> 0.2`，再取并集；连续活动帧形成原始事件。人声每事件独立默认前后扩展 1 秒，并截断到录像边界，不套用枪声的 5 秒分组。笑声、歌唱、尖叫不在此 v1 消费列表；阈值是原型启发式，不代表准确率。

`result.categories.gunshot/voice` 是增量字段，旧顶层 `events/candidates/selection` 和枪声 ID 保持原样。类别保存原始事件、候选范围、策略、类别覆盖和状态。完整十类有效分数得出的零事件为 `completed`；完全缺失、部分类别缺失、没有帧分别为 `unavailable`，带明确原因。无类别记录的旧工程仍显示枪声，并提示暂无可用人声分数。

原生枪声和人声各占一行、独立折叠，单击事件沿用原片预览定位。跨类别重叠保留，展示使用“人声候选”，不按模型子类推断人物、性别、转写或分离声部。识别结果整体随已有工程识别元数据保存；原始事件和待剪范围接入 #24 时分开维护。
