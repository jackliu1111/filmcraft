# #24：独立待剪范围、边界编辑与手动补片

2026-10-16。分支 `codex/selection-ranges-24`。原生真实操作仍由集成验收记录补充，本文件不据自动测试关闭工单。

## 行为与复用

- `Project.selection_ranges` 保存项目内独立的 `SelectionRange`：稳定 `rangeId`、类别、来源结果/事件标识、原片 `start/duration`（Tick）、版本、手动补片与边界修改标记。识别事件和已创建时间线片段不随范围修改。
- 根据原始事件创建默认范围：枪声前后各 5 秒、人声各 1 秒，在原片边界截断并对齐源媒体帧。已有合并组稿候选不替代每个原始事件的独立范围。
- 新识别关联在同一工程事务中初始化范围；旧 #21 工程只有完成识别记录时，查询派生默认，第一次人工操作再持久化。刷新识别只刷新未改过的默认值，保留人工范围及手动补片。
- 鼠标左右手柄复用原生 `source_monitor::adjust_range` 的帧约束；拖动期间仅保留临时预览，释放一次提交。左边界预览首帧，右边界预览最后一个包含的帧；原生源播放头负责画面定位。
- 范围主体和左右边界有独立命中区。主体选中与预览，空白处拖动手动画选；主体拖入成片由 #26 接入，本票不创建时间线片段。
- Escape 放弃未提交预览；切换工程、源素材或遇到其他工程编辑也取消过期预览。所有已提交修改通过 `Session.edit` 使用原生撤销历史。

## 公共命令

控制通道使用 `engine.execute {command:命令名,params:{…}}`：

- `selection.inspect {item}` → `item / projectToken / ranges / events / categories`。
- `selection.setRange {item,rangeId,start,duration,expectedRevision?,projectToken?}` → 修改后的范围。
- `selection.addRange {item,start,duration,category?,projectToken?}` → 新的手动范围；类别默认枪声。手动范围为 `manual:true`、`eventIds:[]`、`resultId:null`，不虚构模型事件。

时间参数都是原片 Tick，查询同时返回 `startSeconds/endSeconds`。反向、空长度、溢出、越界、不足一帧以及过期版本/工程提交均拒绝。UI 始终传工程身份，边界提交还带范围版本。

## 原生操作入口

- 主体：`selection.<category>.<rangeId>.body`。
- 选中或悬停范围后显示手柄：`selection.<category>.<rangeId>.start` / `.end`。
- 空白划选区域：`selection.<category>.create`，实际拖动须从无范围覆盖处开始。
- 单击选中范围后，`[` 选择起点，`]` 选择终点，左右方向键移动一帧，Shift 加方向键移动十帧，Tab/Shift+Tab 切换同类别范围；空格沿用原片预览。
- Escape 取消当前预览或退出范围焦点；范围焦点中的 Delete/Backspace 不删除成片片段。文本输入拥有焦点时不处理这些范围按键。
- Cmd/Ctrl+Z 进入原生撤销；Shift+Cmd/Ctrl+Z 重做。
