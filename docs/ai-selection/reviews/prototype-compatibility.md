## 已对齐的核心规则

- A1 下枪声、人声双识别子行，原片保留。
- 同一条声画关联剪辑轨，空白处追加，片段边界插入，后续顺延；裁短和删除后合拢。
- 待剪范围与已经创建的片段独立；手动重复保留，提示使用情况。
- 主动组稿采用当前范围、合并重叠，生成独立原稿和编辑副本，保留手动序列。

这些是原型交互与状态逻辑对齐，不能直接将 02、05、06、10 标记为原生功能完成。

## 行为偏差及覆盖缺口

| 项目 | 原型现状与证据 | 对应 ticket / 处理 |
| --- | --- | --- |
| 撤销顺序偏差 | 状态历史只保存剪辑序列，范围调整和手动补片不入历史。状态复现：范围 8–16 → 插入 → 改 7–18 → 撤销，直接删除片段，范围仍为 7–18。 | 04、06 已要求按实际顺序撤销。应先撤销范围修改，再撤销插入。 |
| 原片／成片坐标未分清 | 源定位默认把同一个秒数传给成片定位，单一播放头及时间标签未按操作区域区分。成片到原片的计算已存在，但源操作仍将数值当同一时刻使用。 | 02、09 继续按两种坐标验收；例如原片 31 秒与成片 9 秒须分别标示。 |
| 快捷键焦点保护不足 | 除输入框、下拉框和弹窗外，Shift+Enter 可以回退到上次选择的事件；焦点在播放或工具按钮、已剪片段上时也可能追加旧选片。 | 04、06 已有焦点保护条件；实现时须验证这些具体场景。 |
| 网页演示缺少已剪片段重排 | 网页片段主体只用于选择，边界支持裁边；没有片段移动或重排状态操作。原始桌面端已有片段拖动、声画关联及波纹编辑能力。 | 05 复用原生能力，适配连续剪辑轨的重排与合拢并验收；无需从头实现桌面片段移动。 |
| 全部事件映射缺失 | 手动拖入仅记触发事件；剪辑块显示装饰波形，没有按覆盖范围投影全部枪声、人声。枪声 02 的 22.5–35 秒范围覆盖枪声和人声，片段只关联枪声事件。 | 09 保留完整事件映射、裁边裁除和重复使用投影验收。 |
| 本地素材导入会重置演示状态 | 本地视频载入成功时重新创建原型状态，视频不可读时也重置；既有片段、人工范围和内存快照可能丢失。它是单素材演示替换逻辑。 | 01、08、11 的工程保护约定继续有效；正式导入和失败处理不能照搬演示重置流程。 |
| 普通素材入口未覆盖 | 演示拖入依赖事件 id，素材卡及原片参照没有完整的普通素材范围拖入路径，也不能验证其他原生轨道行为。 | 02 仍可独立开工，06 复用其目标轨语义；不能跳过 02。 |
| 真实识别、声音与恢复未覆盖 | 标记和进度是演示数据，视频是静音代理，多音轨选择不提供真实试听；快照仅页内内存，导出入口不可用。 | 01、03、07、08、11、12 的真实链路验收保持不变。 |
