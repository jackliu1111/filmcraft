# 11：保存重开工程，隔离人工编辑与可复用分析

## What to build

用户保存并重开工程后继续同一份识别与剪辑工作；另一工程使用相同素材时只能复用匹配的完成分析，不能带入人工范围。中断任务由用户主动继续。各前置票已负责新增状态的保存，本票完成跨功能恢复一致性。

**复用与改造范围：** 复用原生工程保存、打开及恢复机制，已有 AI 原稿／副本文件保护、完成分析缓存验证和服务中断清理。新增工作是让识别关联、每个候选的人工范围、剪辑轨身份和任务恢复状态随当前工程一起恢复，并保持跨工程人工编辑隔离。缓存有效性沿用共享分析服务核验。

## Acceptance criteria

- [ ] 关闭应用并重新打开真实工程后，恢复原录像关联、分析音轨、完成识别、人工待剪范围、手动补片、剪辑轨顺序和保留声音。
- [ ] 组稿原稿、编辑副本及已有手动剪辑保持正确关联和独立内容；重开不会把编辑副本当作原稿。
- [ ] 另一工程打开同一原片时，可复用源内容、分析音轨、模型与分析配置匹配的完整分析，不继承原工程人工范围、静音选择或剪辑序列。
- [ ] 通过任务或推理记录证明命中缓存未启动新推理；改变源内容、音轨或模型身份时不错误复用，损坏或缺失结果明确报出并允许用户重试。
- [ ] 应用在排队或分析中退出后，重开恢复可理解的中断状态，不自动续跑、不显示为没有声音；用户主动继续或重试后结果归属正确且不重复建片段。
- [ ] 原素材离线或结果关联缺失时保留已保存人工编辑并提示原因；恢复素材后可继续核对，不以空数据覆盖已有状态。
- [ ] 用两个独立工程及一次真实应用重启完成恢复、隔离、缓存命中／失效和中断继续的端到端演示；事件成片标记可依据保存的来源范围重建。
