# 07：选择分析音轨，同时保留剪辑的原有声音

## What to build

导入多音轨录像时，用户先试听并选择供模型分析的音轨，再把素材范围放入剪辑轨；成片默认保留原有声音，选择游戏声分析不会丢弃麦克风或队伍语音。

**复用与改造范围：** 复用现有音轨探测、分析音轨确认和缓存匹配，以及原生多路音频放置、关联编辑、播放和导出。新增工作是分析前实际试听的接入、分析选择与保留声音的独立状态，以及解除现有 AI 草稿适配层的单音轨限制并验证时间起点映射。多音轨底层支持不能代替这条新流程的真实声音验收。

## Acceptance criteria

- [ ] 单音轨仍自动开始；多音轨在选择前不擅自分析，显示可辨认的音轨信息并能实际试听；确认后仅把选定音轨送给模型。
- [ ] 分析音轨身份参与分析结果及缓存匹配，切换音轨不会复用另一音轨的识别结果。
- [ ] 普通素材范围进入剪辑轨时，默认保留原有可用声音；不因分析选择隐式静音或丢弃其他音轨。用户可主动静音或移除。
- [ ] 声画在界面作为单个编辑单元，多路保留音频仍正确关联来源和时间；保存重开后分析选择与保留声音互不混淆。
- [ ] 使用至少一份游戏声和麦克风分轨的真实录像，核对指定轨识别、片段播放及 FilmCraft 默认导出的实际声音，不能沿用旧单音轨样片作为证明。
- [ ] 对非零媒体起点明确换算并用实际片段核验；暂不支持的素材解读或代理情形在放置前给出原因并保留已有内容，不静默放错声画。
- [ ] 没有可分析音轨、试听失败、素材离线或取消选择时不破坏工程；选择状态可供后续队列接入。

## Blocked by

- 01：导入录像后自动识别枪声并展示原片子行
- 02：普通素材进入声画关联剪辑轨并连续拼接
