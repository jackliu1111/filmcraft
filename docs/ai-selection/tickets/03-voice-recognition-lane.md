# 03：从真实分析结果展示人声候选子行

## What to build

用户在同一原片 A1 下同时看到枪声、人声两类真实候选，能独立展开和定位。复用已保存的完整类别分数提取人声事件，不增加转写、说话人判断或声音分离。

**复用与改造范围：** 复用已有模型推理产出的完整类别分数、缓存及 01 的子行展示和预览定位。新增工作是人声类别选择、候选区间后处理、类别身份与真实效果验证；人声分数已经存在，但人声候选提取仍需补齐。

## Acceptance criteria

- [ ] 从模型实际类别分数提取人声候选，明确并固定所消费的类别和区间规则；可复用匹配的完整预测，不因增加人声展示重复模型推理。
- [ ] 枪声、人声各占一条有文字名称的分类子行；跨类别事件可以在同一原片时段重叠，不相互裁减。
- [ ] 人声指所选分析音轨中可检测的人声，不标成录制者身份、台词或分离声部；单击定位原片预览。
- [ ] 人声默认待剪范围前后各 1 秒，枪声各 5 秒，到原片起止截断；原始事件范围独立保留，为范围编辑提供相同能力入口。
- [ ] 类别、事件、来源与结果身份随工程保存；无可用人声分数与成功分析后无人声候选显示为不同状态，不以空结果掩盖缺失数据。
- [ ] 用包含人声、枪声重叠和无明显人声的真实片段核验区间，记录误检、漏检及局限；不以存在模型类别或演示标记代替效果验证。
