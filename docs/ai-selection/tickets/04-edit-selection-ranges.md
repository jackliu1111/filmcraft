# 04：预览并调整待剪范围，手动划选补片

## What to build

用户点击识别高亮后调整独立的待剪范围，拖动边界查看对应画面，也可在无高亮区域划选补片；修改支持键盘与撤销，始终保留模型事件。

**复用与改造范围：** 复用原生源范围手柄、帧边界约束、边界预览、键盘定位及工程撤销事务。新增工作是每个识别候选各自独立的待剪范围、无事件手动补片及其工程保存。原生单组入点／出点不直接替代每个候选的独立范围；新范围修改接入同一工程历史。

## Acceptance criteria

- [ ] 枪声事件 10–12 秒默认得到 5–17 秒待剪范围；调整为 8–16 秒后事件仍为 10–12 秒，不重跑模型。范围能力按事件类别处理，人声类别可用时采用前后各 1 秒。
- [ ] 左右手柄只调整边界，显示时间与边界画面；高亮主体与边界命中区区分，悬停不会播放或修改。
- [ ] 原片起止外的部分截断，不能提交反向、空长度或越界范围；使用真实媒体预览校验边界。
- [ ] 无高亮处可手动划选范围用于后续选片，不虚构对应模型事件；能取消未提交划选。
- [ ] 提供键盘等效的选中和边界调整；文本输入、播放器与范围操作的焦点不会错误触发删除、拖拽或全局快捷键。
- [ ] 一次完成的范围修改形成一次可撤销操作，按实际发生顺序接入原生编辑历史，不使用与时间线互不知晓的独立撤销栈。
- [ ] 人工范围及手动补片属于当前工程并可保存重开；以真实预览演示默认范围、修改、补片、取消和撤销。
