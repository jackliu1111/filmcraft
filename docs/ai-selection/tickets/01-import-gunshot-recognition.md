# 01：导入录像后自动识别枪声并展示原片子行

## What to build

在 FilmCraft 导入单音轨本地录像后自动分析，在主时间线原片 A1 下浏览枪声候选并定位源预览，分析完成只更新识别结果。实施开头先将现有分析结果接收与主动组稿解耦，再接入新入口；复用现有推理、缓存与原生媒体能力。

**复用与改造范围：** 复用原生素材导入、源预览、时间线缩放及已接通的 Python 分析、进度、取消和结果缓存。新增工作是导入后自动触发、分析与组稿解耦、原片参照及识别分类子行的工程关联。现有枪声推理和结果读取保持为共享能力，验收重点是新入口与既有编辑的保护。

## Acceptance criteria

- [ ] 单音轨导入启动一次真实分析，显示进度；结果关联正确原录像和分析音轨，切换素材或工程后，迟到结果不写入错误对象。
- [ ] 完成后显示真实枪声候选及其原片时间，不生成草稿、不移动或覆盖既有剪辑；原有主动组稿能力仍可显式调用。
- [ ] 保留 V1/A1 原片参照，枪声识别子行在 A1 下展开或折叠；缩放、滚动与原片播放位置对齐，不重置用户自定义面板布局。
- [ ] 单击事件定位源预览；悬停仅显示控件，不播放、不改片；类别与分析状态有文字标识。
- [ ] 原片参照属于选片工作区，不因展示而加入成片渲染；原片区域明确标示原片时间。
- [ ] 区分未分析、分析中、完成无候选、失败和不可分析；失败或无音轨不清空已有剪辑。新增已完成识别关联可随工程保存。
- [ ] 以实际单音轨录像演示导入、分析、结果浏览和定位；行为回归覆盖取消及切换工程后结果保护，并证明显式组稿与既有模型入口未退化。
