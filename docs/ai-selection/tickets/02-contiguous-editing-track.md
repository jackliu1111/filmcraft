# 02：普通素材进入声画关联剪辑轨并连续拼接

## What to build

用户把普通原生素材范围拖入一条剪辑轨，画面与关联声音作为同一个编辑单元追加或插入，并能保存、播放和用原生导出检查成片。连续拼接由目标剪辑轨决定，后续 AI 选片复用同一规则。

**复用与改造范围：** 复用原生素材范围拖入、关联声画放置、插入、吸附、拖动反馈、撤销、保存和导出。新增工作是将关联声画在一行剪辑轨中呈现，并让该目标轨默认连续追加、边界插入及后续顺延；原片参照另用于选片。先核验既有放置路径，再补足目标轨语义和展示差异。

## Acceptance criteria

- [ ] 原生素材以一个声画关联单元显示在同一条剪辑轨，底层保留视频与音频的区分及来源范围；原片参照不被移走。
- [ ] 将原片 8–16 秒放入空轨形成成片 0–8 秒；将 30–36 秒拖到任意轨道空白位置，紧接为成片 8–14 秒，不在鼠标远端留下空隙。
- [ ] 把 20–23 秒拖到两段之间时吸附边界，形成成片 8–11 秒，原第二段顺延到 11–17 秒；不覆盖内容。
- [ ] 拖动预览准确显示最终追加或插入位置、时长和后续位移；Esc 或无效落点不提交；一次撤销恢复关联声画及全部插入位移。
- [ ] 其他原生轨道保留自身编辑行为；轨道身份与片段来源映射随工程保存，重开后仍按目标轨规则操作。
- [ ] 剪辑轨区域显示成片时间，源预览显示对应原片位置，不用一个标签混指两个坐标。
- [ ] 使用 FilmCraft 默认参数实际导出包含剪辑点的片段，核对顺序、范围、声音和时长；完整原片参照不混入成片。

## Blocked by

None (can start immediately)
