# 12：真实录像完成选片、重开与原生后台导出验收

## What to build

从真实录像导入到人工选片、组稿、保存重开和 FilmCraft 原生后台导出，验证这轮原生改造完整可用，记录模型效果、长录像表现和操作效率；修复暴露出的集成问题。

**复用与改造范围：** 复用 FilmCraft 现有后台导出、默认参数、任务取消／重试和提交时工程快照，以及已有媒体验证方式。本票承担新选片流程的集成验收和暴露问题的修复；导出器、播放引擎和编码预设沿用现有实现。旧流程通过的场景作为回归基线，新增状态和交互仍需真实样本证据。

## Acceptance criteria

- [ ] 在同一完整流程覆盖单音轨自动分析、多音轨试听选择、多素材排队、两类识别、范围调整、手动补片、拖入与键盘追加、边界插入、删改重排和撤销。
- [ ] 验证原片参照不变且不混入渲染、手动重复保留、组稿重叠合并、当前范围被采用、原稿不被副本修改，以及重新打开工程后继续编辑。
- [ ] 实际导出一个覆盖多个剪辑点的完整短序列，沿用 FilmCraft 默认参数；完整解码并核对每段范围、顺序、帧边界、声画同步及多音轨应保留的声音。
- [ ] 导出期间允许继续编辑，成片对应提交时的序列快照；取消或失败不破坏当前剪辑，应用内后台导出状态可见。
- [ ] 以真实枪声、人声及混合样本逐段核验区间，记录误检、漏检与补片成本；不把候选数量或流程成功当作识别准确率达标。
- [ ] 选取长录像记录首次分析耗时、结果浏览与缩放响应、关键交互卡顿；和旧流程使用同一素材、同一选片目标比较操作步骤、误操作及完成时间，不预设效率倍数。
- [ ] 分别记录自动化行为检查、原生界面操作及实际媒体证据，标明样本、系统、版本与未覆盖项；演示数据、旧多轨原型及旧单音轨导出记录不作为本轮验收。
- [ ] 本轮范围为已确认的 FilmCraft 本机原生改造；文字转写、说话人分离、声音分类分离导出和完整跨平台发行迁移不随本票引入。
