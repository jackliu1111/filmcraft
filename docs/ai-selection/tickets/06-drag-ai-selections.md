# 06：拖拽待剪范围加入剪辑轨并提示重复使用

## What to build

用户拖动识别高亮主体或手动划选范围，复用普通素材的目标轨规则创建独立声画片段；也能用 Shift+Enter 追加。创建时提示重复或重叠，允许重复内容。

**复用与改造范围：** 复用原生源素材拖拽载荷、半透明反馈、落点吸附、取消、声画放置和 02 的目标轨规则。新增工作是从识别高亮或手动范围发起拖拽、携带当时范围的独立快照、使用关系及重复提示，并接好键盘焦点和跨范围／片段操作的撤销顺序。

## Acceptance criteria

- [ ] 8–16 秒待剪范围拖入空剪辑轨形成成片 0–8 秒；空白落点或 Shift+Enter 追加末尾，靠近已有片段时吸附边界插入并整体顺延。
- [ ] 使用同一目标轨的普通素材与 AI 范围具有一致结果；不用添加按钮，也不为每次拖入新建 V2/A2、V3/A3 轨道对。
- [ ] 显示半透明声画单元、时长和实际落点，松手提交并短暂高亮；Esc、无效落点和焦点不适用时不创建片段。
- [ ] 拖入采用当时范围，随后把待剪改为 7–18 秒不改变既有 8–16 秒片段；原片参照保持不变。
- [ ] 原片 10–20 秒和 15–25 秒手动加入后连续组成 20 秒，提示已使用或部分重叠，不自动合并或裁掉重复画面。
- [ ] 创建、重复使用及撤销后使用提示及时反映当前序列；新增片段和来源关系可保存。本票验收创建与撤销，裁边、删除、重排后的提示由完整事件映射票验收。
- [ ] 执行拖入、再调整待剪范围、再撤销时，先撤销最近的范围调整；再撤销才移除片段并恢复关联声画和插入位移。
- [ ] 用真实已分析素材走通鼠标拖入和键盘追加，覆盖手动补片及不修改模型事件的行为。

## Blocked by

- 02：普通素材进入声画关联剪辑轨并连续拼接
- 04：预览并调整待剪范围，手动划选补片
