# 05：剪辑片段删改、重排与自动合拢

## What to build

用户在剪辑轨中将画面与关联声音一起裁边、删除或重排，后续片段自动合拢或顺延；通过一次撤销恢复该次编辑产生的全部变化。

复用 FilmCraft 桌面端已有的片段拖动、关联声画、波纹裁边／删除和撤销能力，适配目标剪辑轨的连续拼接规则。重点是重排后的边界插入、原位置合拢、关联声音同步及整次操作撤销；普通原生轨道继续沿用自身编辑语义。网页原型缺少重排交互，不代表桌面端需要从头实现片段移动。

## Acceptance criteria

- [ ] 片段作为声画单元被选中、裁边、删除和重排，各保留音频与视频保持相同原片范围及成片位置。
- [ ] 在成片 0–8、8–11、11–17 秒三段中删除中间段后总长为 14 秒；首段再缩短 2 秒，第二段同步提前 2 秒，连续无缝。
- [ ] 延长片段时保持原片边界合法并顺延后续片段；重排后重新计算位置，不覆盖、复制或丢失内容。
- [ ] 原片参照与识别事件不变；存在待剪范围时，片段裁边不回写它。其他原生轨道不受该轨合拢规则改变。
- [ ] 拖动重排或裁边时，预览与实际提交结果一致；取消不产生修改，一次撤销恢复内容、声音、顺序及全部受影响位置。
- [ ] 编辑历史遵循用户真实操作顺序，焦点和快捷键遵循原生交互；新片段状态和顺序可保存重开。
- [ ] 以原生界面操作并播放实际片段验证声画与顺序，覆盖首段、末段、删除全部及越界调整。
