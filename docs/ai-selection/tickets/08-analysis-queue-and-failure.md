# 08：多素材分析排队、取消及失败处理

## What to build

一次导入多个素材后，应用有序分析并展示每项状态，用户可继续预览编辑、取消或重试；多音轨素材先等待用户选择，不把未完成分析显示为没有声音。

**复用与改造范围：** Python 服务已支持多素材顺序分析、任务进度、取消、逐项结果和中断清理；当前原生桥主要承接一次单素材请求。新增工作是在桌面入口接入待选音轨、排队、取消及重试状态，并把结果关联到正确素材和工程。批量处理沿用现有分析服务，原生导出队列继续负责导出。

## Acceptance criteria

- [ ] 多个单音轨素材按明确顺序排队；多音轨素材先进入待选择状态，确认后再进入分析队列，同一请求不重复提交。
- [ ] 等待或运行分析时可继续预览和编辑；完成结果只关联对应素材并展示，不替换当前手动剪辑。
- [ ] 明确区分等待选择、排队、运行、已完成、取消、失败和不可用；完成无事件与未完成不是同一种状态。
- [ ] 可取消排队及运行任务，取消后迟到结果不覆盖工程；失败原因可见，用户可主动重试，重试不会重复生成片段。
- [ ] 素材离线、无音轨、服务退出或某项分析失败时，保留已完成结果、人工范围和已有剪辑，其他任务状态保持一致。
- [ ] 队列及中断状态随工程记录，启动应用或重开工程不自动重新提交未完成任务；恢复后的主动继续在工程恢复票中验证。
- [ ] 用多素材混合案例实际演示排队、等待音轨选择、编辑并行、取消及一次失败重试，核对任务数量和结果归属。
