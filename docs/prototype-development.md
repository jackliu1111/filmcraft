# AI 识别与选片原型开发说明

2026-10-16。状态：原型阶段生效。当前开发原则见 [AGENTS.md](../AGENTS.md)。本文件描述本轮原型的工作范围和验证方式，上游规范作为参考。

## 当前目标

在 FilmCraft 中体验：导入录像、分析声音、浏览枪声和人声分类子行、调整待剪范围、把声画加入连续剪辑轨，再复用原生编辑和导出。

优先复用已有素材拖入、源范围、片段移动、声画关联、波纹编辑、撤销、工程保存及导出。网页原型没有展示某项操作，不表示原始桌面端没有对应能力。

本轮侧重功能与交互验证；正式安装分发、完整平台支持、纯 Rust 产品承诺和上游贡献门禁由后续任务决定。

## 工具与实现

允许直接修改 Rust 源码，复用共享 Python 分析引擎，并使用 FFmpeg/ffprobe 或网页演示完成验证。不为遵守纯 Rust 形式重新实现已有模型或媒体工具。

当前可从已有进程与 NDJSON 接入方式继续演进；先约定本次使用的请求、进度、取消、错误及结果格式，记录引擎版本和配置。小型原型无需先建设插件平台、通用任务系统或完整安装器。

优先让编辑器管理工程状态、识别关联和剪辑，让共享模型引擎管理推理与预测。若用临时方案，清楚写明其保存范围、运行环境和限制。

AI 缺失、取消或失败应给出可理解的状态，并保留原片和已有编辑。模型事件、人工范围及已剪片段相互独立。将分析时间转换成原生编辑时间时，检查帧率、媒体起点和音轨偏移。

## 一次任务怎么完成

1. 阅读任务及相关源码，确认能复用的能力和实际缺口。
2. 选择一条完整、可演示的细路径，在专用分支完成改动。
3. 按影响范围做编译、语法和关键行为检查；必要时补回归测试。
4. 实际体验交互；涉及真实分析、保存重开或导出时，分别取得对应证据。
5. 记录样本、版本、结果和未覆盖部分，再据验收条件更新任务状态。

如果只改文档，核对链接和规则一致性即可；不要求运行应用测试。原型改动不默认附加全仓测试、WASM、所有编解码器、多平台验收、资产索引或正式打包任务。

仓库已有编译器约束和工作流仍由实际配置执行。若检查失败，说明具体原因和影响；文档放宽不等于构建已通过，也不要求为了原型批量删除现有检查。

## 证据和素材

按实际覆盖范围说明结果：

- 浏览器演示：布局、点击、拖拽及模拟状态。
- 真实模型：实际输出的枪声／人声候选及区间效果。
- 原生应用：可操作界面、编辑语义和撤销。
- 工程恢复：实际磁盘保存、进程重启及跨工程隔离。
- 导出：真实文件中的范围、顺序、时长、声音及声画同步。

可以先用演示数据回答交互问题，再接入真实引擎。演示通过不能自动完成真实链路验收。

个人录像、权重、模型缓存和大型运行证据使用本地目录；公开提交的素材保留来源和必要署名。先复用现有原型素材和许可信息，再决定哪些文件适合随源码迁入。

## 正式化时再核对

准备发布或提交上游时，集中核对完整 CI、平台和 WASM 兼容、依赖与打包、素材与署名、上游命令／分层／自动化要求，以及原型临时代码的整理。这些事项由对应任务安排，不是当前每个原型切片的前置门槛。
